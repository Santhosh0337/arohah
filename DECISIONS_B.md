# Decisions (Person B)

Short entries: date, decision, reason.

## 2026-11-07, Phase B1

1. **Provider interfaces copied verbatim from `docs/API_CONTRACT.md` section 5** (`providers/base.py`). The contract wins over the bible where they differ: `transcribe()` takes `mixed_language`, and `synthesize()` returns `(bytes, mime)`. Two small additions that do not change any signature: `@runtime_checkable` on the three Protocols (so tests and callers can use `isinstance`) and `from __future__ import annotations`.
2. **Mock-first.** `providers/mock.py` holds `MockSTT`, `MockTTS`, `MockLLM`. Each has `is_mock = True`. The STT text starts with `[MOCK]`, returns no words (no invented timestamps or confidence), and `raw.mock` is `true`. TTS returns half a second of silent WAV. The LLM returns an object shaped like the requested schema, with `"[MOCK]"` strings, 0, `False` and `[]`. For an `enum` it uses the first listed value only to stay schema-valid; that is not a real choice. Callers that act on an LLM result (the voice intent fallback, later) must check `provider_status()["llm"]` and skip the fallback when it is `mock`.
3. **Live integration deferred.** No live adapter exists, and live testing was skipped on purpose. `registry._LIVE_FACTORIES` holds `None` for each service, so `provider_status()` returns `mock` for all three. A service is `live` only when `USE_MOCKS` is not true, a key is set, and a factory is registered. A key alone never makes a service live. To add an adapter later: set the factory for that service (one line) and write the adapter in `providers/gnani_*.py`.
4. **Registry configuration** uses the bible section 14 names: `GNANI_PRISMA_API_KEY`, `GNANI_TIMBRE_API_KEY`, `GNANI_LLM_API_KEY` (each overrides `GNANI_API_KEY`), `GNANI_*_BASE_URL`, `GNANI_LLM_MODEL`, `USE_MOCKS`. They are read from `os.environ` at call time; the registry does not load `.env` itself. Factories receive a `ServiceConfig(api_key, base_url, model)`.
5. **Demo languages: English, Tamil, Hindi.** Telugu and Malayalam are future plans only and are not in `languages.json`. The `demo` flag here means "selected for the product demo". This is looser than bible 16.2, which says a language may be a demo language only once Prisma is confirmed and the tests pass. Every entry stays `prisma: unconfirmed`, `timbre: unconfirmed`, `command_keywords: false`, `tested: false`. Raised in `OPEN_QUESTIONS_B.md`.
6. **`languages.json` is a bare array** of `Language` objects. `GET /api/languages` wraps it as `{ "languages": [...] }` (contract 2.2). Mixed language is the checkbox, not a row.
7. **Language codes** `en-IN`, `ta-IN`, `hi-IN` come from the bible matrix, where only `hi-IN` was seen on Gnani's site and the others are marked "confirm". They are not verified provider codes.
8. **Frontend stack:** Vite 7, React 19, TypeScript 5.8, Tailwind 4 through `@tailwindcss/vite` (no PostCSS or `tailwind.config.js` needed). Built and checked with Node 22.23 and npm 10.9. The project's Node version is not fixed by the docs, so no `engines` field is set. `package-lock.json` is committed (frontend lockfile is mine).
9. **API client** (`src/api/`) is split into `types.ts` (contract types) and `client.ts` (fetch calls). `createProject` follows the contract's async 202 + polling. Editing routes return `{ data, status }` so the UI can see the 201 fork and must use the returned `id`. Errors become `ApiError` with `status`, `code`, `message`, `details`.
10. **Mock fixtures** (`src/mocks/`) are shape-only, labelled MOCK in names and comments, and shown with a visible notice in the UI. Only `App.tsx` imports them.
11. **Fonts not added yet.** Noto Sans Indic subsets are Phase B2 (bible 16.5). The CSS names `"Noto Sans"` first with system fallbacks, and Indic text gets `lang` and a taller line height already.
12. **Files outside the Phase B1 list:** `backend/requirements/gnani.txt` (comments only, because `requirements.txt` includes it and pip fails if it is missing), `providers/__init__.py`, `backend/tests/providers/*` (bible rule 7), `frontend/.gitignore`, `frontend/.env.example`. No Prettier or Ruff config was added, since the plan has A commit those on Day 0.

## 2026-11-08, Phase B2 (capture and visualize)

13. **No new npm dependencies.** The waveform is drawn on a canvas from peaks computed in `audio/waveform.ts`, and playback uses Web Audio (`audio/player.ts`). Wavesurfer.js (named in bible F3) was left out: it needs a new dependency and a lockfile change, and I cannot regenerate `package-lock.json` offline. Playback uses a decoded buffer rather than an `<audio>` element because MediaRecorder WebM often cannot seek. Wavesurfer can be adopted later without touching the form.
14. **Frontend tests use Node's built-in runner, not Vitest.** `npm test` runs `node --test "src/**/*.test.ts"` (Node 22 strips TypeScript types). So pure logic lives in plain `.ts` modules with explicit `.ts` import paths (`allowImportingTsExtensions`), and React components hold no logic worth testing. Component rendering is not unit tested; it was checked in a real browser instead (see PHASE_B2_TEST_REPORT.md). Test files are excluded from `tsconfig.app.json` and type-checked by `tsconfig.test.json`; `npm run typecheck` runs both.
15. **Language dropdown and the unverified-language rule.** The dropdown lists every language from `GET /api/languages`. A language is selectable only if `prisma === "confirmed"`. Because none is confirmed yet, I added a dev flag `VITE_ALLOW_UNVERIFIED_LANGUAGES=true` (in `.env.example`) that also allows `unconfirmed` ones, labelled "not verified" and with a visible note. It never allows `unsupported`. It does not make Prisma work and changes no status in `languages.json`. This answers open question 6 provisionally; Person B/the human can drop the flag once Gnani confirms.
16. **Three ways to start, kept honest.** "Create project" calls the real API. "Preview waveform (no backend)" shows the user's real clip with fixture notes. "Load the fixture project" shows synthetic audio with fixture notes. Each result carries a banner saying which it is. Stage progress appears only from `GET /api/projects/{id}/status`; nothing is simulated.
17. **Async create is isolated in `lib/projectRun.ts`** (create, then poll once a second, then load). If A makes creation synchronous, only that file changes. See open question 9.
18. **Fixture audio is synthesised in the browser** (`audio/fixtureAudio.ts`, sine tones from the fixture notes), so no binary audio file is committed.
19. **Recording details.** 3-second get-ready countdown, then a countdown of remaining time. The recorder stops at 59.5 s so the decoded clip cannot land just over the 60 s limit. WebM and MP4/M4A recordings are sent as they are. A browser that records something else (Firefox: OGG) has the clip converted to 16-bit mono WAV in the browser (`audio/wav.ts`), because the API does not accept OGG.
20. **Validation limits.** 1 to 60 s (contract). Upload size limit 25 MB is my choice (the bible asks for a size limit but gives no number). Duration is read by decoding the audio in the browser, so a file the browser cannot decode is rejected with a message suggesting WAV or MP3.
21. **Languages route** (`api/languages.py`): reads `backend/data/languages.json`, falls back to `backend/app/data/languages.json` (the team plan tree and CODEOWNERS disagree on the folder), validates each row with Pydantic (`models_gnani.py`), normalises to NFC, and returns `{ "languages": [...] }`. The router carries the `/api` prefix itself. A broken file returns 500 with the contract error body.
22. **Language tests live in `backend/tests/providers/`** (`test_languages_api.py`) because that is the only Person B test folder that exists in the plan besides `intents/`. `httpx` was added to `requirements/gnani.txt` for FastAPI's TestClient.
23. **Fonts.** `@font-face` rules are in `public/fonts/fonts.css`, linked from `index.html` (so Vite never tries to bundle files that may be missing). The six `.woff2` binaries are not included because they could not be downloaded in the build environment; `npm run fonts` fetches them. Until then the CSS falls back to locally installed Noto fonts and then the system stack. Nothing fake sits in `public/fonts/`.
24. **Hook and lib folders.** Added `src/hooks/` and `src/lib/` next to the planned `components/`, `audio/` and `api/`. `src/pages/` was not needed yet.
25. **Bundled language fallback.** If `GET /api/languages` fails, `useLanguages` uses `MOCK_LANGUAGES` and shows a visible notice. This is the one place outside the fixture view that imports `src/mocks/`; it keeps the form usable before A's API exists and carries the same statuses as the server file.
